# Labs

Six programming labs, 30% of the module grade. Python 3.11+, NumPy and PyTorch; labs 4–6 run on the local fleet.

Every lab is handed in as a repository folder with the code, a `README.md` with how to run it, a short write-up of results (one page), the answer to the reflection question, and a statement of which AI tools you used and for what. Grading: 60% correctness, 25% write-up, 15% reflection.

| Lab | Topic | Set |
|---|---|---|
| [Lab 1](lab1-astar/README.md) | Route planner with A* | after lecture 3 |
| [Lab 2](lab2-naive-bayes/README.md) | Naive Bayes spam filter | after lecture 5 |
| [Lab 3](lab3-mlp-numpy/README.md) | A neural network from scratch | after lecture 7 |
| [Lab 4](lab4-tiny-transformer/README.md) | A tiny Transformer on your GPU | after lecture 10 |
| [Lab 5](lab5-local-inference/README.md) | Measuring local inference | after lecture 11 |
| [Lab 6](lab6-rag-agent/README.md) | A RAG agent on your own router | after lecture 13 |
