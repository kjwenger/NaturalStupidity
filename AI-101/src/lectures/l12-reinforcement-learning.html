Reinforcement learning

Learning what to do from trial, error and reward, without anyone showing the right answer. The framework behind game-playing agents, robot control and the final training stage of today's LLMs.

  • Write down the Bellman equations and run value iteration.

12.1 Markov decision processes

Definition 12.1 (MDP)

A Markov decision process consists of states \(S\), actions \(A\), transition probabilities \(P(s' \mid s, a)\), a reward function \(R(s, a, s')\) and a discount factor \(\gamma \in [0, 1)\). The Markov property says that the next state depends only on the current state and action, not on the history.

A policy \(\pi(a \mid s)\) says what to do in each state. The goal is a policy that maximises the expected return, the discounted sum of rewards \(G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \dots\). Discounting makes infinite sums finite and prefers rewards sooner rather than later.

The value function \(V^\pi(s)\) is the expected return from \(s\) when following \(\pi\); the action-value \(Q^\pi(s,a)\) is the expected return after taking \(a\) in \(s\) and then following \(\pi\).

12.2 Bellman equations and dynamic programming

The optimal values satisfy the Bellman optimality equation:

\[ V^*(s) = \max_a \sum_{s'} P(s' \mid s,a)\,\big[R(s,a,s') + \gamma V^*(s')\big]. \]

The value of a state is the best immediate reward plus the discounted value of where you end up. If the model \(P, R\) is known, value iteration turns this equation into an update and repeats it until the values converge; the optimal policy then picks the maximising action in each state.

Example 12.1 (A three-state corridor)

States A – B – C; C is terminal with reward +10 on entering it; each move costs −1; moves are deterministic; \(\gamma = 0.9\). Starting from \(V = 0\): after one iteration \(V(B) = 9\) (step to C: \(-1 + 10\)), \(V(A) = -1\). After two, \(V(A) = -1 + 0.9 \cdot 9 = 7.1\). The values then stay fixed: the policy "move right" is optimal.

12.3 Learning without a model: Q-learning

Usually the agent does not know \(P\) and \(R\); it must learn by acting. Q-learning keeps a table of estimates \(Q(s,a)\) and, after each transition \((s, a, r, s')\), moves the estimate towards the observed reward plus the best estimated future:

\[ Q(s,a) \leftarrow Q(s,a) + \alpha\big[r + \gamma \max_{a'} Q(s',a') - Q(s,a)\big]. \]

The bracket is the temporal-difference error. Q-learning converges to \(Q^*\) if every state–action pair is tried often enough, which raises the exploration–exploitation dilemma: exploit the best known action, or explore one that might be better? The simplest answer is \(\varepsilon\)-greedy: act randomly with probability \(\varepsilon\), otherwise greedily.

For large state spaces, a neural network replaces the table. DeepMind's DQN (2015) learned to play 49 Atari games from raw pixels this way.

12.4 Policy gradients and RL for LLMs

Instead of learning values, we can parameterise the policy \(\pi_\theta\) directly and follow the gradient of expected return. The policy gradient theorem gives

\[ \nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta}\big[\nabla_\theta \log \pi_\theta(a \mid s)\; \hat A(s,a)\big], \]

where the advantage \(\hat A\) measures how much better an action did than expected: make good actions more likely, bad ones less likely. PPO adds a limit on how far each update may move the policy.

An LLM is a policy: the state is the text so far, the action is the next token. In RLHF, a complete response gets a score from a reward model trained on human preferences, and PPO (or simplified variants like GRPO) adjusts the model to produce higher-scoring responses, with a penalty for drifting too far from the SFT model. With verifiable rewards (correct maths answer, tests pass) this is how reasoning models learned to think step by step.

Reward hacking. An agent optimises the reward you wrote, not the one you meant. A coding model rewarded for passing tests may learn to edit the tests. Lecture 14 returns to this.

Summary

  • MDPs formalise sequential decisions; policies are judged by expected discounted return.
  • The Bellman equation links a state's value to its successors'; value iteration solves known MDPs.
  • Q-learning learns from experience without a model, balancing exploration and exploitation.
  • Policy gradients optimise the policy directly; RLHF and RL with verifiable rewards apply them to LLMs.

  1. Compute the return for rewards (−1, −1, −1, +10) with γ = 0.9. [2 pts]
    Solution

    −1 − 0.9 − 0.81 + 0.729·10 = −2.71 + 7.29 = 4.58.

  2. Perform one Q-learning update: Q(s,a) = 2, r = 1, max Q(s′,·) = 5, α = 0.1, γ = 0.9. [2 pts]
    Solution

    Target 1 + 0.9·5 = 5.5; TD error 3.5; new Q = 2 + 0.35 = 2.35.

  3. In example 12.1, add a fourth state D to the left of A. What is V*(D) and how many iterations does value iteration need to get there? [3 pts]
    Solution

    V*(D) = −1 + 0.9·7.1 = 5.39. Values propagate one state per iteration, so it is correct after three iterations.

  4. Why does RLHF penalise the KL divergence from the SFT model? [3 pts]
    Solution

    The reward model is only accurate near the responses it was trained on. Without the penalty, the policy drifts to strange outputs that exploit the reward model's errors (reward hacking) and can lose fluency and general ability.
