Machine learning fundamentals

Instead of programming the answer, we program a way to learn it from examples. This lecture sets out the vocabulary and the central problem: generalising to data the model has never seen.

Learning objectives

  • Distinguish supervised, unsupervised, self-supervised and reinforcement learning.
  • State empirical risk minimisation and explain overfitting, underfitting and the bias–variance trade-off.
  • Set up a sound evaluation with training, validation and test sets and appropriate metrics.

6.1 Kinds of learning

  • Supervised learning: learn a function \(f: x \mapsto y\) from labelled pairs \((x_i, y_i)\). If \(y\) is a category, it is classification; if it is a number, regression.
  • Unsupervised learning: find structure in unlabelled data, e.g. clusters (k-means), low-dimensional projections (PCA) or the data distribution itself.
  • Self-supervised learning: create labels from the data itself, e.g. predict the next word of a text or a masked patch of an image. This is how LLMs are pre-trained, and it is why they can use the whole internet as training data.
  • Reinforcement learning: learn from rewards for actions (lecture 12).

6.2 Learning as optimisation

We choose a model class, functions \(f_\theta\) with parameters \(\theta\), and a loss function \(L(\hat y, y)\) that measures how wrong a prediction is. Training means empirical risk minimisation:

\[ \hat\theta = \arg\min_\theta \frac{1}{N}\sum_{i=1}^{N} L\big(f_\theta(x_i),\, y_i\big). \]

Common losses are the squared error \((\hat y - y)^2\) for regression and the cross-entropy \(-\log \hat p(y)\) for classification, where \(\hat p(y)\) is the probability the model assigns to the correct class. Minimising cross-entropy is exactly maximum likelihood estimation (lecture 5).

Linear and logistic regression

Linear regression predicts \(\hat y = w^\top x + b\). With squared loss it has a closed-form solution. Logistic regression is the simplest classifier: it squashes a linear score through the sigmoid \(\sigma(z) = 1/(1+e^{-z})\) to get a probability, \(\hat p(y=1 \mid x) = \sigma(w^\top x + b)\). Its decision boundary is a hyperplane. For \(K\) classes, the softmax generalises the sigmoid:

\[ \mathrm{softmax}(z)_k = \frac{e^{z_k}}{\sum_j e^{z_j}}. \]

A neural network classifier is the same thing with a learned, non-linear feature extractor in front (lecture 8). Every LLM ends in a softmax over its vocabulary.

6.3 Generalisation

What matters is not the training loss but the error on new data from the same distribution, the generalisation error.

Definition 6.1 (Overfitting and underfitting)

A model overfits when it fits the training data, including its noise, much better than new data: low training error, high test error. It underfits when it is too simple to capture the pattern: both errors are high.

Classically, expected test error decomposes as

\[ \text{error} = \text{bias}^2 + \text{variance} + \text{noise}. \]

Bias is error from wrong assumptions (a straight line through a parabola). Variance is sensitivity to the particular training sample. More flexible models have less bias and more variance: this is the bias–variance trade-off.

Double descent. Very large neural networks break the classical U-curve: past the point where they fit the training data perfectly, test error falls again as models grow. Why over-parameterised networks generalise is still an active research question.

Regularisation fights overfitting by preferring simpler models: an L2 penalty \(\lambda\lVert\theta\rVert^2\) on the weights (weight decay; the MAP estimate with a Gaussian prior), L1 for sparsity, early stopping, dropout, data augmentation, and above all more data.

6.4 Evaluating models honestly

Split the data three ways: a training set to fit parameters, a validation set to choose hyperparameters (model size, learning rate, \(\lambda\)), and a test set used once, at the end, to report performance. Every decision made by looking at test results leaks information and makes the reported number optimistic. With little data, use k-fold cross-validation: train \(k\) times, each time holding out a different fold.

Choose the metric to fit the task:

  • Accuracy misleads on imbalanced data: a fraud detector that always says "no fraud" is 99.9% accurate.
  • Precision = TP / (TP + FP): of the items flagged, how many are right. Recall = TP / (TP + FN): of the real positives, how many were found. F1 is their harmonic mean.
  • For LLMs, held-out loss or perplexity during training, and task benchmarks afterwards (lecture 14).

Summary

  • Supervised learning minimises an average loss over training examples; cross-entropy is maximum likelihood.
  • The goal is generalisation. Too simple underfits, too flexible overfits; regularisation and more data help.
  • Keep the test set untouched until the end, and pick metrics that fit the cost of each kind of error.

Exercises (Sheet 6)

  1. A classifier for a rare disease (1% prevalence) finds 80 of 100 sick patients in a test set of 10,000, and flags 400 healthy patients. Compute accuracy, precision, recall and F1. [4 pts]
    Solution

    TP = 80, FN = 20, FP = 400, TN = 9,500. Accuracy = 9,580 / 10,000 = 95.8%. Precision = 80 / 480 ≈ 0.167. Recall = 0.8. F1 = 2·0.167·0.8 / (0.967) ≈ 0.28.

  2. You tune 50 hyperparameter settings, picking the best by test-set accuracy, and report that accuracy. What is wrong, and how do you fix it? [3 pts]
    Solution

    The test set was used for model selection, so the reported number is biased upward (you picked the setting that got luckiest on that set). Select on a separate validation set (or with cross-validation) and evaluate only the final choice once on the test set.

  3. Training loss is 0.02 and validation loss 0.95, and validation loss has been rising for several epochs. Diagnose and name three remedies. [3 pts]
    Solution

    Overfitting. Remedies: early stopping at the validation minimum, stronger regularisation (weight decay, dropout), more or augmented data, or a smaller model.

  4. Show that for a single example with true class \(y\), the cross-entropy loss of a softmax classifier is \(-z_y + \log\sum_j e^{z_j}\). [3 pts]
    Solution

    −log softmax(z)_y = −log(e^{z_y} / Σ_j e^{z_j}) = −z_y + log Σ_j e^{z_j}. This "log-sum-exp" form is how frameworks compute it, for numerical stability.
