Neural networks and backpropagation

Stack simple units in layers, add non-linearities, and train every weight at once with the chain rule. This is the engine of all of deep learning.

Learning objectives

  • Compute the forward pass of a multilayer perceptron.
  • Derive and run backpropagation on a small network.
  • Explain the role of activation functions, initialisation, normalisation and dropout.

8.1 From neurons to networks

An artificial neuron computes a weighted sum of its inputs plus a bias and passes it through an activation function: \(a = g(w^\top x + b)\). Rosenblatt's perceptron (1958) used a step function and could learn any linearly separable classification. Minsky and Papert showed in 1969 that a single perceptron cannot learn XOR, which contributed to the first AI winter.

The fix is to stack layers. A multilayer perceptron (MLP) with layers \(\ell = 1, \dots, L\) computes

\[ h^{(0)} = x, \qquad h^{(\ell)} = g\big(W^{(\ell)} h^{(\ell-1)} + b^{(\ell)}\big), \qquad \hat y = W^{(L)} h^{(L-1)} + b^{(L)}. \]

Without the non-linearity \(g\), the layers would collapse into one linear map. With it, an MLP is a universal approximator: a single hidden layer with enough units can approximate any continuous function on a bounded domain. In practice deep networks need far fewer units than shallow ones for the same function, because they compose features hierarchically.

Activation functions

  • Sigmoid and tanh: smooth, but they saturate. For large inputs their derivative is near zero, which blocks learning in deep networks (vanishing gradients).
  • ReLU \(\max(0, z)\): cheap, does not saturate for positive inputs. The default since about 2011.
  • GELU and SwiGLU: smooth relatives of ReLU used in Transformers. Qwen, Llama and most current LLMs use SwiGLU in their feed-forward layers.

8.2 Backpropagation

To train with gradient descent we need \(\partial L / \partial W\) for every weight. Backpropagation computes all of them in one backward sweep through the network, applying the chain rule layer by layer and reusing intermediate results. Its cost is about twice that of the forward pass, independent of how many parameters there are.

Write \(z^{(\ell)} = W^{(\ell)} h^{(\ell-1)} + b^{(\ell)}\) and \(\delta^{(\ell)} = \partial L/\partial z^{(\ell)}\). Then

\[ \delta^{(\ell)} = \big(W^{(\ell+1)\top}\delta^{(\ell+1)}\big)\odot g'\big(z^{(\ell)}\big), \qquad \frac{\partial L}{\partial W^{(\ell)}} = \delta^{(\ell)}\, h^{(\ell-1)\top}, \qquad \frac{\partial L}{\partial b^{(\ell)}} = \delta^{(\ell)}. \]
Example 8.1 (Backprop on a tiny network)

One input \(x = 1\), one hidden ReLU unit with weight \(w_1 = 0.5\), output weight \(w_2 = 2\), target \(y = 3\), loss \(L = \tfrac12(\hat y - y)^2\).

Forward: \(z_1 = 0.5\), \(h = 0.5\), \(\hat y = 1\), \(L = 2\).
Backward: \(\partial L/\partial \hat y = \hat y - y = -2\). \(\partial L/\partial w_2 = -2 \cdot h = -1\). \(\partial L/\partial h = -2 \cdot w_2 = -4\); ReLU passes it through since \(z_1 > 0\), so \(\partial L/\partial w_1 = -4 \cdot x = -4\).
With \(\eta = 0.1\): \(w_1 = 0.9\), \(w_2 = 2.1\); the new output is \(1.89\), closer to 3.

Modern frameworks (PyTorch, JAX) do this automatically: automatic differentiation records the operations of the forward pass as a graph and runs the chain rule backwards through it.

History. The algorithm was found several times; Rumelhart, Hinton and Williams' 1986 paper made it widely known and ended the first neural-network winter.

8.3 Making deep networks trainable

  • Initialisation: weights drawn with variance about \(2/n_{\text{in}}\) (He initialisation for ReLU) keep activations and gradients at a stable scale from layer to layer. All-zero weights would make every unit in a layer identical forever.
  • Normalisation: batch normalisation (CNNs) or layer normalisation and RMSNorm (Transformers) rescale activations inside the network, allowing higher learning rates and deeper models.
  • Residual connections \(h + F(h)\) give the gradient a direct path through many layers (lecture 9).
  • Dropout: during training, randomly zero a fraction of activations. The network cannot rely on any single unit, which regularises it.

Summary

  • An MLP alternates linear maps and non-linearities; depth lets it build features hierarchically.
  • Backpropagation is the chain rule applied efficiently, at about twice the cost of a forward pass.
  • Careful initialisation, normalisation, residual connections and dropout make deep nets train well.

Exercises (Sheet 8)

  1. Give weights for a 2-2-1 MLP with step activations that computes XOR. [4 pts]
    Solution

    Hidden unit 1 computes OR: step(x₁ + x₂ − 0.5). Hidden unit 2 computes AND: step(x₁ + x₂ − 1.5). Output: step(h₁ − h₂ − 0.5), i.e. OR and not AND.

  2. Count the parameters of an MLP with layer sizes 784 → 256 → 128 → 10. [2 pts]
    Solution

    784·256 + 256 = 200,960; 256·128 + 128 = 32,896; 128·10 + 10 = 1,290. Total 235,146.

  3. Repeat example 8.1 with \(w_1 = -0.5\). What happens, and what is this problem called? [3 pts]
    Solution

    z₁ = −0.5, ReLU outputs 0, so ŷ = 0 and L = 4.5. ∂L/∂w₂ = −3·0 = 0 and the ReLU derivative is 0, so ∂L/∂w₁ = 0 as well. No weight moves: a "dead ReLU". Leaky ReLU or GELU avoid exact zeros.

  4. Why does stacking sigmoid layers lead to vanishing gradients? Use the maximum of σ′. [3 pts]
    Solution

    σ′(z) ≤ 0.25. Backprop multiplies one such factor per layer, so after 10 layers the gradient is scaled by at most 0.25¹⁰ ≈ 10⁻⁶ (ignoring weights): early layers barely learn.
