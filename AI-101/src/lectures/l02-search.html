Lecture 2 · Week 2 · Part I Classical AI

Problem solving by search

When an agent knows how the world works, it can plan by searching through possible action sequences. This lecture covers the formal setup and the core algorithms, from breadth-first search to A*.

Learning objectives

  • Formulate a problem as a search problem: states, actions, transition model, goal test, path cost.
  • Run BFS, DFS, uniform-cost search and A* by hand and state their properties.
  • Design admissible and consistent heuristics and prove that A* is then optimal.

2.1 Search problems

Definition 2.1 (Search problem)

A search problem consists of: a set of states \(S\); an initial state \(s_0\); for each state, a set of applicable actions \(A(s)\); a transition model \(\mathrm{Result}(s,a)\); a goal test; and an action cost \(c(s,a,s') \ge 0\). A solution is a sequence of actions from \(s_0\) to a goal state; an optimal solution has the lowest total path cost.

The states and actions implicitly define a graph, the state space. It is usually far too large to write down: the 15-puzzle has about \(10^{13}\) states, chess about \(10^{44}\). Search algorithms therefore build a search tree on the fly, expanding one node at a time. The set of generated but not yet expanded nodes is the frontier. Algorithms differ only in which frontier node they expand next.

Example 2.1 (Route finding)

States: cities. Actions: drive along a road to a neighbouring city. Cost: kilometres. Goal: arrive in Munich. The state space is the road map itself.

Measuring algorithms

We judge search algorithms by four criteria: completeness (does it always find a solution if one exists?), optimality (does it find a cheapest one?), and time and space complexity, expressed with the branching factor \(b\) (maximum number of successors), the depth \(d\) of the shallowest solution and the maximum depth \(m\).

2.2 Uninformed search

Uninformed (blind) strategies use only the problem definition.

  • Breadth-first search (BFS) expands the shallowest node first, using a FIFO queue. It is complete, and optimal when all action costs are equal. Time and space are both \(O(b^d)\); in practice memory runs out first.
  • Uniform-cost search (UCS, Dijkstra's algorithm) expands the node with the lowest path cost \(g(n)\), using a priority queue. It is complete and optimal for positive costs.
  • Depth-first search (DFS) expands the deepest node first, using a stack. It needs only \(O(bm)\) memory but is neither complete (infinite paths) nor optimal.
  • Iterative deepening runs depth-limited DFS with limits 0, 1, 2, … It combines DFS's small memory with BFS's completeness and optimality for unit costs. Re-expanding the shallow levels costs surprisingly little, because most nodes are in the deepest level.

Graph vs. tree search. Keeping a set of already reached states avoids exploring the same state twice through different paths. Without it, even a small grid produces an exponential tree.

2.3 Informed search and A*

Definition 2.2 (Heuristic)

A heuristic \(h(n)\) estimates the cost of the cheapest path from node \(n\) to a goal. It is admissible if it never overestimates: \(h(n) \le h^*(n)\) for the true cost \(h^*\). It is consistent if \(h(n) \le c(n,a,n') + h(n')\) for every successor \(n'\) (a triangle inequality).

Greedy best-first search expands the node with the smallest \(h(n)\). It is fast but not optimal: it chases whatever looks closest. A* search expands the node with the smallest

\[ f(n) = g(n) + h(n), \]

the estimated cost of the cheapest solution through \(n\).

Theorem 2.1 (Optimality of A*)

With an admissible heuristic, A* tree search is optimal. With a consistent heuristic, A* graph search is optimal, and it expands every node at most once.

Proof sketch. Suppose a suboptimal goal \(G_2\) is on the frontier, and let \(n\) be a frontier node on an optimal path to the optimal goal \(G\) with cost \(C^*\). Then \(f(n) = g(n) + h(n) \le C^*\) by admissibility, while \(f(G_2) = g(G_2) > C^*\) since \(h(G_2) = 0\). So \(n\) is expanded before \(G_2\), and by induction the whole optimal path is expanded first. \(\square\)

Example 2.2 (Heuristics for the 8-puzzle)

\(h_1\): number of misplaced tiles. \(h_2\): sum of the Manhattan distances of the tiles from their goal squares. Both are admissible, because every move fixes at most one tile by at most one square. Since \(h_2(n) \ge h_1(n)\) for all \(n\), \(h_2\) dominates \(h_1\) and A* with \(h_2\) never expands more nodes. At solution depth 24, A* with \(h_1\) expands about 39,000 nodes, with \(h_2\) about 1,600.

Good heuristics often come from relaxed problems: remove a constraint and solve the easier problem exactly. If tiles could move to any adjacent square even when occupied, the exact solution cost would be \(h_2\).

Summary

  • Search algorithms differ only in the order they expand frontier nodes.
  • BFS and UCS are complete and optimal but memory-hungry; DFS is frugal but neither; iterative deepening gets the best of both for unit costs.
  • A* with \(f = g + h\) is optimal for admissible (tree) or consistent (graph) heuristics. Better heuristics mean far fewer expansions.

Exercises (Sheet 2)

  1. A graph has nodes S, A, B, C, G with edges S–A (1), S–B (4), A–B (2), A–C (5), B–C (1), C–G (3). Heuristic: h(S)=5, h(A)=4, h(B)=3, h(C)=2, h(G)=0. Run UCS and A* from S to G. Give the expansion order and the path found. [6 pts]
    Solution

    UCS: expand S (0); frontier A(1), B(4). Expand A (1); B improves to 3 via A, C(6). Expand B (3); C improves to 4. Expand C (4); G(7). Expand G (7). Order S, A, B, C, G. Path S–A–B–C–G, cost 7.

    A*: f(S)=5. Expand S; A: f=1+4=5, B: f=4+3=7. Expand A; B via A: f=3+3=6, C: f=6+2=8. Expand B (6); C via B: f=4+2=6. Expand C (6); G: f=7+0=7. Expand G. Same order and path, cost 7. Check: h is admissible (true costs to G: S 7, A 6, B 4, C 3).

  2. Show that the straight-line distance is an admissible heuristic for route finding on a road map. Is it consistent? [3 pts]
    Solution

    No road between two points is shorter than the straight line, so it never overestimates. It is also consistent: by the triangle inequality, the straight-line distance from n to the goal is at most the road length from n to n′ plus the straight-line distance from n′ to the goal.

  3. Why is iterative deepening's overhead small? Compute the number of generated nodes for b = 10, d = 5 and compare with BFS. [4 pts]
    Solution

    Level i is generated (d − i + 1) times: N(IDS) = 5·10 + 4·100 + 3·1,000 + 2·10,000 + 1·100,000 = 123,450. BFS generates 10 + 100 + 1,000 + 10,000 + 100,000 = 111,110. The overhead is about 11%, because the last level dominates.

  4. Is h(n) = max(h₁(n), h₂(n)) admissible if h₁ and h₂ are? Is it better than each? [2 pts]
    Solution

    Yes: both are ≤ h*, so their maximum is too. It dominates both, so A* expands no more nodes than with either one, at the price of computing both.
